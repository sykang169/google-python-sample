# FINLIFE 필드 용어 풀이

응답의 필드명은 축약된 로마자라 뜻을 짐작하기 어렵다. 아래는 그 대응표다.
`baseList`와 `optionList`는 서버가 `(fin_co_no, fin_prdt_cd)`로 이미 조인해
`products[].options[]` 형태로 돌려준다.

## 공통 (모든 상품군)

| 필드 | 뜻 |
| --- | --- |
| `dcls_month` | 공시 기준월 `YYYYMM`. **데이터의 시점** |
| `fin_co_no` | 금융회사 코드 |
| `kor_co_nm` | 금융회사명 |
| `fin_prdt_cd` | 금융상품 코드 |
| `fin_prdt_nm` | 금융상품명 |
| `join_way` | 가입방법 (영업점 / 인터넷 / 스마트폰 / 전화) |
| `dcls_strt_day` | 공시 시작일 |
| `dcls_end_day` | 공시 종료일. 비어 있으면 계속 판매 중 |
| `fin_co_subm_day` | 금융회사 제출일 `YYYYMMDDHH24MI` |

## 예금 · 적금

| 필드 | 뜻 | 해석 시 주의 |
| --- | --- | --- |
| `mtrt_int` | 만기 후 이자율 | 만기 방치 시 급락. 장기 비교에 영향 |
| `spcl_cnd` | 우대조건 | `intr_rate2`의 전제. 자유 서술 텍스트 |
| `join_deny` | 가입제한 | `1` 제한없음 / `2` 서민전용 / `3` 일부제한 |
| `join_member` | 가입대상 | |
| `etc_note` | 기타 유의사항 | |
| `max_limit` | 최고한도(원) | `null`이면 한도 없음 또는 미기재 |
| `intr_rate_type` / `_nm` | `S` 단리 / `M` 복리 | 장기 상품에서 실수령액이 갈린다 |
| `rsrv_type` / `_nm` | `S` 정액적립식 / `F` 자유적립식 (적금만) | |
| `save_trm` | 저축 기간(개월) | 보통 1/3/6/12/24/36 |
| `intr_rate` | 저축금리(%) — **기본** | `null`이면 해당 기간 미취급 |
| `intr_rate2` | 최고우대금리(%) | 우대조건 전부 충족 시 |

> 적금 금리를 예금 금리와 나란히 비교하지 않는다. 적금은 매월 납입하므로
> 같은 표면금리라도 실제 이자는 대략 절반 수준이다. 굳이 비교하려면
> 총 수령이자로 환산하고, 환산했다고 밝힌다.

## 주택담보대출 · 전세자금대출

| 필드 | 뜻 |
| --- | --- |
| `loan_inci_expn` | 대출 부대비용 (인지세, 감정평가수수료 등) |
| `erly_rpay_fee` | 중도상환수수료 |
| `dly_rate` | 연체이자율 |
| `loan_lmt` | 대출한도 |
| `mrtg_type` / `_nm` | 담보유형 (아파트 등). 주담대만 |
| `rpay_type` / `_nm` | 상환방식 — 분할상환방식 / 만기일시상환방식 |
| `lend_rate_type` / `_nm` | 금리유형 — 고정금리 / 변동금리 |
| `lend_rate_min` | 최저금리(%) |
| `lend_rate_max` | 최고금리(%) |
| `lend_rate_avg` | 전월 취급 평균금리(%) |

> `lend_rate_min`으로 순위를 매기지 않는다. 최저금리는 최우량 차주 기준이라
> 대부분의 사용자에게 해당하지 않는다. **비교의 기준선은 `lend_rate_avg`**이고,
> min~max는 범위로 함께 보여 준다.
>
> 고정금리와 변동금리를 같은 표에서 단순 비교하지 않는다. 금리유형이 다르면
> 위험 구조가 다르다 — 별도 행으로 나누고 `lend_rate_type_nm`을 표기한다.

## 개인신용대출

| 필드 | 뜻 |
| --- | --- |
| `crdt_prdt_type` / `_nm` | 대출 종류 (일반신용대출, 마이너스한도대출 등) |
| `cb_name` | 사용한 신용평가사 (NICE, KCB 등) |
| `crdt_lend_rate_type` / `_nm` | 금리 구분 |
| `crdt_grad_*` | 신용점수 구간별 금리 — 구간표는 SKILL.md 참조 |
| `crdt_grad_avg` | 평균 금리 |

> `cb_name`이 회사마다 다르다. NICE 점수와 KCB 점수는 같은 사람에게도 다르게
> 나오므로, 서로 다른 CB를 쓰는 회사의 같은 구간 금리를 비교할 때는
> 어느 평가사 기준인지 표기한다.
>
> 마이너스한도대출과 일반신용대출은 금리 체계가 다르다. `crdt_prdt_type_nm`으로
> 나눠서 비교한다.

## 금융회사

| 필드 | 뜻 |
| --- | --- |
| `homp_url` | 홈페이지 |
| `cal_tel` | 콜센터 전화번호 |
| `dcls_chrg_man` | 공시 담당자 |
| `area_cd` / `area_nm` | 영업 지역 |
| `exis_yn` | 해당 지역 영업 여부 |

> **저축은행은 영업 지역 제한이 있다.** 금리가 가장 높은 저축은행이
> 사용자가 사는 지역에서 영업하지 않을 수 있다. 저축은행을 추천 목록에 넣을
> 때는 `list_financial_companies`로 `area_nm`을 확인하거나,
> 최소한 "영업 지역 확인 필요"를 유의사항에 적는다.
