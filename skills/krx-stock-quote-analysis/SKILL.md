# 국내 주식 시세 분석

금융위원회가 data.go.kr로 제공하는 **일자별 확정 시세**다. 실시간 호가가 아니라
장 마감 후 확정되는 일별 데이터이며, 이 차이가 답의 정확성을 좌우한다.

## 핵심 규칙

> [!IMPORTANT]
> 이 API는 잘못 물어도 **오류를 내지 않고 다른 답을 준다.** 그게 가장 위험하다.

1. **상품군마다 도구가 다르다.** 주식은 `get_stock_price`, ETF는
   `get_etf_price`, ETN은 `get_etn_price`, 채권은 `get_bond_price`,
   지수는 `get_market_index`다. **주식 도구에 ETF를 물으면 0건이 나온다** —
   데이터가 없어서가 아니라 도구를 잘못 고른 것이다. ELW와 주가지수선물은
   `search_apis`로 찾아 `call_api`로 실행한다.
2. **모르는 필터 이름은 조용히 무시된다.** `mrktCtg`에 `"NASDAQ"`을 넘기면
   오류 없이 **필터가 적용되지 않은 전체 결과**가 돌아온다. 필드명을 지어내지 말고
   `search_apis`가 알려준 `fields`에서 고르며, 조회 후 반환된 행의 값을 실제로
   확인한다. 시장 구분 허용값은 `KOSPI` / `KOSDAQ` / `KONEX`뿐이다.
3. **조건 없이 호출하지 않는다.** 종목도 기간도 안 주면 최신 일자부터 전체를
   훑는다. 종목(`itmsNm` 등)이나 기간(`basDt` / `beginBasDt`+`endBasDt`)을
   최소 하나는 지정한다.
4. **정확 일치와 부분 일치를 구분한다.** `itmsNm="삼성전자"`는 보통주만,
   `likeItmsNm="삼성전자"`는 `삼성전자우`까지 포함한다. 우선주가 섞이면
   수익률 계산이 오염된다.

## 도구 선택

| 도구 | 대상 |
| --- | --- |
| `get_stock_price` | 주식(주권). KOSPI/KOSDAQ/KONEX |
| `get_market_index` | 주가지수. 대표지수 + 섹터지수. **벤치마크의 출처** |
| `get_etf_price` | ETF |
| `get_etn_price` | ETN |
| `get_bond_price` | 채권 시세 |
| `find_listed_item` | KRX 상장종목 마스터. ISIN 확정 |
| `search_apis` / `call_api` | ELW, 주가지수선물, 채권지수, 금·석유·배출권 |

채권의 **발행조건·권리일정·스프레드**는 이 스킬이 아니라
[kr-bond-ficc-analysis](../kr-bond-ficc-analysis/SKILL.md)다. 여기는 시세만 다룬다.

## 종목 지정 방법

도구는 `params` 딕셔너리로 필터를 받는다 — 예:
`get_stock_price({"itmsNm": "삼성전자"})`. 키 이름은 **응답 필드명과 같다.**

| 필드 | 의미 | 언제 |
| --- | --- | --- |
| `itmsNm` | 종목명 정확 일치 | 종목이 확정된 단일 종목 분석 |
| `likeItmsNm` | 종목명 부분 일치 | 종목명이 불확실하거나 계열 전체 |
| `isinCd` | ISIN 12자리 (`KR7005930003`) | **가장 정확하다.** 반복 조회에 권장 |
| `likeSrtnCd` | 단축코드 부분 일치 (`005930`) | 부분 일치임에 주의 |
| `mrktCtg` | 시장 구분 | `KOSPI` / `KOSDAQ` / `KONEX` |

종목명이 모호하면(동음 종목, 우선주, 스팩) 먼저 `find_listed_item`이나
`likeItmsNm`으로 후보와 `isinCd`를 확인하고, 이후 조회는 `isinCd`로 고정한다.
이 습관 하나가 종목 오인을 대부분 막는다.

## 기간 조회

| 인자 | 형식 | 용도 |
| --- | --- | --- |
| `basDt` (params) | `YYYYMMDD` | 특정 하루 |
| `beginBasDt` + `endBasDt` (params) | `YYYYMMDD` | 기간 |
| `rows` (도구 인자) | 정수 (최대 권장 100) | 페이지당 건수 |
| `page` (도구 인자) | 정수 | 페이지 번호 |

`rows`와 `page`는 `params` 밖의 도구 인자다 —
`get_stock_price({"itmsNm": "삼성전자", "beginBasDt": "20260801"}, rows=100)`.

> [!WARNING]
> **휴장일에는 데이터가 없다.** 주말·공휴일을 `basDt`로 주면 빈 결과가
> 나오고, 이는 오류가 아니다. "최근 종가"를 물으면 하루를 딱 집지 말고
> 최근 7~10일을 기간으로 조회해 **가장 최신 `basDt`의 행**을 쓴다.
> 데이터 반영에도 지연이 있으므로 오늘 날짜에 데이터가 없는 것도 정상이다.

기간이 길면 `rows` 기본값 20에 잘려 앞부분만 받게 된다. 영업일 수를 어림해
(1개월 ≈ 20영업일, 1년 ≈ 245영업일) `rows`를 넉넉히 주거나 `page`를 순회하고,
받은 행 수가 기대보다 적으면 **잘렸다고 의심한다.**

## 응답 필드

| 필드 | 뜻 | 단위 |
| --- | --- | --- |
| `basDt` | 기준일자 | `YYYYMMDD` |
| `srtnCd` | 단축코드 | |
| `isinCd` | ISIN | |
| `itmsNm` | 종목명 | |
| `mrktCtg` | 시장 구분 | KOSPI/KOSDAQ/KONEX |
| `clpr` | 종가 | 원 |
| `vs` | 전일 대비 | 원 |
| `fltRt` | 등락률 | % |

| `trqu` | 거래량 | 주 |

값은 모두 **문자열**이다. 계산 전에 숫자로 변환하고, 빈 문자열은 0이 아니라
결측으로 다룬다.

## 오류 코드

data.go.kr은 HTTP 200과 함께 `resultCode`로 결과를 준다.

| 코드 | 뜻 | 대응 |
| --- | --- | --- |
| `03` | 데이터 없음 | 휴장일·종목명 오타·수록 범위 밖. 오류가 아니다 |
| `10` / `11` | 잘못된/누락된 파라미터 | 인자 형식 확인 |
| `22` | 요청 제한 초과 | 잠시 후 재시도. 조회 횟수를 줄인다 |
| `30` / `31` / `32` | 서비스키 문제 | 재시도해도 소용없다. 설정 문제로 보고 |

## 상류가 막혔을 때

금융위 API는 짧은 시간에 호출이 몰리면 **소스 IP 단위로 접속을 수 분간 막는다.**
그때는 도구가 다음 형태로 답한다.

- `apis.data.go.kr에 연결하지 못했습니다` — 연결 자체가 막혔다
- `연결이 반복 실패해 N초 동안 호출을 멈춥니다` — 서버가 회로를 닫아 상류를 쉬게 하는 중

둘 다 **데이터가 없다는 뜻이 아니다.** 사용자에게 "지금 조회할 수 없다"고 알리고,
기억이나 웹 검색으로 주가를 채우지 않는다. 잠시 후 다시 시도하면 된다.

같은 조회를 반복하지 않는다. 서버가 응답을 캐시하므로 정상일 때는 반복 조회가
저렴하지만, 막힌 상태에서 재시도를 반복하면 차단이 길어진다.

## 계산할 때의 함정

- **액면분할·병합**을 보정하지 않는다. 분할 전후 종가를 그대로 이어 수익률을
  계산하면 -80% 같은 값이 나온다. `lstgStCnt`가 특정 일자에 급변하면 신호다.
  의심되면 그 사실을 답변에 밝힌다.
- **우선주를 섞지 않는다.** `likeItmsNm` 결과에 `우`, `2우B` 등이 들어온다.
- **거래정지·관리종목**은 같은 종가가 반복된다. 변동성이 0에 가까우면 확인한다.
- **수익률**은 `(기말 종가 / 기초 종가 − 1) × 100`. 배당은 반영되지 않으므로
  총수익률이 아니라 **가격수익률**임을 밝힌다.
- **초과수익률**은 종목 수익률 − 지수 수익률이다. `get_market_index`로 같은
  기간의 벤치마크를 받아 계산하고, 어느 지수를 썼는지(`idxNm`) 밝힌다.
  코스닥 종목을 코스피와 비교하지 않는다 — `idxCsf`로 계열을 맞춘다.
- **변동성**은 일간 로그수익률의 표준편차 × √245 (연율화). 표본 기간을 함께 쓴다.
- **시가총액**은 `mrktTotAmt`를 그대로 쓴다. `clpr × lstgStCnt`로 직접 계산하면
  우선주·자기주식 때문에 공시값과 어긋난다.

## 하지 말아야 할 것

> [!CAUTION]
> **시세 해석과 투자권유는 다르다.** 목표주가, 매수/매도 의견, "지금이
> 저점입니다" 같은 표현은 자본시장법상 투자권유로 읽힐 수 있다.
> 경계와 필수 고지는 [kr-financial-ai-compliance](../kr-financial-ai-compliance/SKILL.md)를 읽는다.

- 조회한 데이터에 없는 값을 기억으로 채우지 않는다. 주가는 기억으로 답하면 반드시 틀린다.
- 실시간 시세인 것처럼 말하지 않는다. 일별 확정 데이터이고 기준일을 항상 명시한다.
- 해외주식은 이 API의 범위 밖이다. 수록되지 않았다고 분명히 말한다.
  **옵션시세는 이 서버에 없다.** 권한은 있으나 응답이 비어 돌아와 스키마를 확인하지
  못해 카탈로그에서 제외했다. 주가지수선물(`getStockFuturesPriceInfo`)은 `search_apis`로
  찾아 쓸 수 있다.
