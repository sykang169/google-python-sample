## 연결 vs 별도

`fs_div` 파라미터로 고른다.

| 값 | 뜻 | 언제 |
| --- | --- | --- |
| `CFS` | 연결재무제표 | **기본값으로 삼는다.** 그룹 전체의 실질을 본다 |
| `OFS` | 별도(개별)재무제표 | 지주회사의 별도 실적, 배당 재원, 자회사 없는 회사 |

같은 회사의 매출액이 연결과 별도에서 크게 다른 것은 정상이다. 어느 쪽인지
밝히지 않고 수치를 인용하면 그 자체로 틀린 답이 된다.
종속회사가 없는 회사는 `CFS`가 비어 있고 `OFS`만 존재한다 — 이때 `status 013`이
날 수 있으므로 `OFS`로 한 번 더 시도한다.

## 응답 필드

`list` 배열의 각 행에서 실제로 쓰는 것들:

| 필드 | 뜻 |
| --- | --- |
| `sj_div` / `sj_nm` | 재무제표 구분 코드 / 이름 |
| `account_id` | 표준 계정 ID (IFRS 태그). 비표준 계정은 `-표준계정코드 미사용-` |
| `account_nm` | 계정명(한글). 회사마다 표기가 다르다 |
| `thstrm_amount` | 당기 금액 |
| `frmtrm_amount` | 전기 금액 |
| `bfefrmtrm_amount` | 전전기 금액 |
| `thstrm_nm` / `frmtrm_nm` | 각 기간의 이름 (예: "제 56 기") |
| `currency` | 통화. 보통 `KRW` |
| `ord` | 보고서 내 표시 순서 |

## 재무제표 구분

`sj_div` 값으로 필터링한다.

| 코드 | 재무제표 |
| --- | --- |
| `BS` | 재무상태표 |
| `IS` | 손익계산서 |
| `CIS` | 포괄손익계산서 |
| `CF` | 현금흐름표 |
| `SCE` | 자본변동표 |

회사에 따라 손익을 `IS`로만, 또는 `CIS`로만 제출한다. **둘 다 조회해 존재하는
쪽을 쓴다.** 영업이익이 안 보인다면 대개 이 이유다.

## 계정 식별

`account_nm`(한글 계정명)만으로 매칭하면 회사별 표기 차이("매출액" / "수익(매출액)" /
"영업수익")에 걸려 넘어진다. 가능하면 `account_id`의 IFRS 태그로 매칭하고,
없을 때만 이름으로 떨어진다.

자주 쓰는 표준 태그:

| 항목 | account_id |
| --- | --- |
| 자산총계 | `ifrs-full_Assets` |
| 유동자산 | `ifrs-full_CurrentAssets` |
| 부채총계 | `ifrs-full_Liabilities` |
| 유동부채 | `ifrs-full_CurrentLiabilities` |
| 자본총계 | `ifrs-full_Equity` |
| 매출액 | `ifrs-full_Revenue` |
| 영업이익 | `dart_OperatingIncomeLoss` |
| 당기순이익 | `ifrs-full_ProfitLoss` |

> [!WARNING]
> 태그는 회사·연도별로 달라질 수 있고 `-표준계정코드 미사용-`인 행도 흔하다.
> 태그로 못 찾으면 `account_nm` 부분 일치로 폴백하되, **어떤 계정명을 썼는지
> 답변에 밝힌다.** 계정을 못 찾았으면 0으로 치환하지 말고 "해당 계정 없음"으로 보고한다.

## 금액 정규화

- 원 단위 **문자열**이고 천 단위 쉼표가 들어 있다 → `int(v.replace(",", ""))`
- 음수는 `-1,234` 또는 `(1,234)` 두 형태가 모두 나온다
- 빈 문자열 `""`이 오는 행이 있다 → 0이 아니라 "값 없음"이다
- 사람에게 보여줄 때는 조/억 단위로 환산한다 (`1조 2,345억원`)

## 대표 지표 계산식

계산에 쓴 계정과 기간을 항상 함께 표기한다.

| 지표 | 식 | 주의 |
| --- | --- | --- |
| 부채비율 | 부채총계 / 자본총계 × 100 | 자본잠식(자본총계 ≤ 0)이면 계산하지 말고 "자본잠식"으로 보고 |
| 유동비율 | 유동자산 / 유동부채 × 100 | 금융업은 유동/비유동 구분이 없어 의미가 없다 |
| 영업이익률 | 영업이익 / 매출액 × 100 | 매출액 0이면 계산 불가 |
| 순이익률 | 당기순이익 / 매출액 × 100 | |
| ROE | 당기순이익 / 자본총계 × 100 | 엄밀히는 평균자기자본. 단일 시점 값이면 그렇게 밝힌다 |
| ROA | 당기순이익 / 자산총계 × 100 | |
| EPS·PER | 공시된 값을 쓴다 | 시가총액이 필요하면 시세 스킬을 쓴다 — DART에 없다 |

> [!CAUTION]
> **은행·보험·증권은 위 지표를 그대로 쓰면 안 된다.** 부채가 곧 예수금인
> 업종이라 부채비율 1,000%가 정상이다. 금융업 분석은 BIS 자기자본비율,
> NIM, 고정이하여신비율, 지급여력비율(K-ICS) 같은 업권 지표를 쓰고,
> 이 값들은 재무제표가 아니라 각 사 경영공시·감독당국 통계에 있다.

## 기간 비교

한 번의 호출로 당기·전기·전전기가 함께 오므로(`thstrm` / `frmtrm` / `bfefrmtrm`)
3개년 추이는 **추가 호출 없이** 만들 수 있다. 연도를 바꿔가며 반복 호출하는 것은
분당 1,000건 제한을 낭비하는 흔한 실수다.

분기 실적을 볼 때는 누적/분기 구분에 주의한다. `reprt_code=11014`(3분기)의
손익은 3분기 **누적**인 경우가 많다. 단일 분기 값이 필요하면
누적 − 직전 누적으로 직접 계산하고, 그렇게 계산했다고 밝힌다.
