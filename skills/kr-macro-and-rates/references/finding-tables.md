# 통계표 찾기 레시피

`search_statistic_tables(stat_name=...)`는 **통계표 이름 부분 일치**다.
사용자가 쓰는 말과 한국은행이 쓰는 통계표 이름이 다르기 때문에, 질문을
그대로 검색어로 넣으면 0건이 나오기 쉽다. 아래는 그 번역표다.

> [!IMPORTANT]
> 여기 있는 것은 **검색어**이지 통계표 코드가 아니다. 코드는 반드시 검색 결과에서
> 읽어 온다. 검색어도 후보일 뿐이므로, 0건이면 더 짧고 일반적인 말로 다시 찾는다.

## 사용자 표현 → 검색어

| 사용자가 묻는 것 | 검색어 후보 | 비고 |
| --- | --- | --- |
| 기준금리, 정책금리 | `기준금리`, `여수신금리` | 정책금리는 일별(`D`)로 봐야 변경일이 보인다 |
| 예금·대출 금리(은행 평균) | `여수신금리`, `가중평균금리` | 개별 회사 금리는 ECOS에 없다 → FINLIFE |
| 시장금리, 국고채, CD | `시장금리` | 만기별로 세부항목이 갈린다 |
| 환율 | `환율` | 매매기준율·종가 등 계열이 여럿 |
| 물가, 인플레이션 | `소비자물가`, `생산자물가` | **지수**다. 상승률은 직접 계산 |
| 성장률, GDP | `국민계정`, `국내총생산` | 분기·연 주기. 속보/잠정 개정 있음 |
| 통화량, M1/M2 | `통화 및 유동성`, `본원통화` | |
| 가계부채 | `가계신용` | 분기 |
| 수출입, 경상수지 | `국제수지`, `무역` | |
| 실업률, 고용 | `고용`, `경제활동인구` | 원출처는 통계청. ECOS에도 수록 |
| 부동산 가격 | `주택`, `지가` | 원출처는 한국부동산원 |
| 기업경기, 소비심리 | `경제심리지수`, `기업경기실사지수` | BSI/CSI |
| 외환보유액 | `외환보유액` | |

## 검색이 0건일 때

1. 검색어를 **짧게** 한다. `원달러환율` → `환율`, `소비자물가상승률` → `물가`
2. `searchable_only=False`로 상위 분류까지 본 뒤, 그 아래 조회 가능한 표를 찾는다
3. 용어 자체가 낯설면 `search_statistic_glossary(word)`로 한국은행이 쓰는
   정식 명칭을 확인하고 그 말로 다시 검색한다
4. 그래도 없으면 **ECOS에 없는 통계일 수 있다.** 개별 금융회사 판매 금리,
   개별 종목 시세, 기업 재무제표는 ECOS의 범위가 아니다

## 후보가 여러 개일 때 고르는 법

`list_statistic_items(stat_code)`를 후보마다 한 번씩 호출해 다음을 비교한다.

- `START_TIME` / `END_TIME` — 질문의 기간을 실제로 덮는가
- `DATA_CNT` — 너무 적으면 중단된 통계다
- `CYCLE` — 원하는 주기가 있는가
- `ITEM_NAME1` — 원하는 계열(예: "원/미국달러(매매기준율)")이 있는가

`END_TIME`이 몇 년 전에서 멈춘 표는 **폐지되었거나 다른 표로 이관된 것**이다.
최신 값을 묻는 질문에 이런 표를 쓰면 오래된 숫자를 최신인 것처럼 답하게 된다.

## 여러 지표를 한 화면에 볼 때

`list_key_statistics(start, end)`가 100대 지표의 최신값을 한 번에 준다.
"현재 거시 상황 요약" 같은 질문은 여기서 시작하고, 그중 사용자가 파고드는
지표만 `get_statistic_series`로 시계열을 뽑는다. 처음부터 여러 통계표를
개별 조회하면 `ERROR-602`(호출 제한)에 걸린다.
